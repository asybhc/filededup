# 文件去重 Go 版 0.10.10

发布日期 2026-11-16 ｜ 提交 `c82c029` ｜ 便携版 `fdedup-ui.exe` 14,187,520 字节 ｜ SHA-256 `43256C4AE3A73C957D7DC547A6393AE58231939BB585E8ACCE19CD9456AF93CD`

本版补齐 P1 清单的 11 项功能缺口，0.10.0–0.10.10 逐项独立提交。

## 查重

- **全盘查重**（0.10.5）：自动枚举固定卷，硬排除 Windows、Program Files、ProgramData、$Recycle.Bin、System Volume Information、Recovery、Windows.old 等目录与各卷根的分页/休眠文件；新增 64KB 快筛，同尺寸文件先比对头部哈希，命中才进完整 SHA-256 复核，分组、保留与删除仍以完整哈希为准。
- **结果页筛选与排序**（0.10.4）：按关键字、类型筛选，按指定字段升降序，筛选只影响显示、不改动勾选范围。
- **相似图片大图预览**（0.10.4）：抽屉内按需加载，限制 1600px、做 EXIF 方向校正、不落临时文件，超大图与解码失败会说明原因。
- **打开所在位置**（0.10.10）：每个成员行可直接在资源管理器中定位该文件，失败在页内报错。

## 整理

- **按时间整理**（0.10.2）：日 / ISO 周 / 月 / 年分桶，EXIF 拍摄时间优先、取不到回退修改时间；支持移动或复制，冲突可选改名 / 跳过 / 覆盖；跨卷移动自动退化为复制，走临时文件加尺寸校验再原子重命名；目标落在源目录内时自动跳过目标子树。
- **规则预设与规则测试器**（0.10.8）：整理规则可命名保存为预设（配置目录 `FileDedup/organize-presets.json`，带版本号、严格校验、原子写入、损坏不静默清空）；测试器对样例名做纯计算，逐条给出改后名称、特殊判定与最终去向，不读盘不写盘。
- **整理完成后打开目标文件夹**（0.10.9）：仅真实执行完成后出现，试运行与仅规划不显示。
- **危险源拒绝**（0.10.10）：扫描与整理统一拒绝整盘卷根和 12 类系统目录，提示改选具体子目录并引导全盘查重走对应入口。

## 检索与诊断

- **Everything 可选后端**（0.10.6）：在本地文件系统之外可选 `es.exe` 检索，未安装时选项禁用并说明修复方式；过滤口径与本地后端一致，支持取消并保留已有结果。
- **日志与环境自检**（0.10.3）：日志可列出、看尾部、打开目录、二次确认清除；环境页汇总版本平台、配置目录写探针、日志占用、回收站、es.exe、磁盘剩余、更新缓存。

## 界面

- **中英双语**（0.10.7）：全界面本地化，815 条词条，顶栏徽标加设置项切换，缺键回退中文。
- **拖放与快捷键**（0.10.1）：目录可直接拖入路径框，仅该区域响应并高亮；F1 打开帮助浮层，Esc 按层级收起。
- **执行中关闭确认**（0.10.0）：扫描、删除、整理、本地搜索、网盘上传进行中关闭或从托盘退出时提示，默认「继续执行」；关闭到托盘不打扰。

## 升级须知

- 普通扫描与整理现在会拒绝整盘卷根和系统目录，需要选具体子目录；整盘查重请使用「全盘查重」入口，该模式不受此限。
- 全盘查重的 64KB 快筛与相似图片检测互斥，同时开启会直接提示原因。
- 相似图片默认关闭、阈值上限收紧到 16（自 0.9.8 起），旧配置已保存的数值保持原值，不会被默认值覆盖。
- 整理目标允许设在源目录之外，跨卷时退化为复制并在界面提前说明源文件保留（自 0.9.9 起）。
- 语言默认中文，可选英文。

## 已知限制

- 后端运行时消息仍为中文，英文界面下错误、阶段、蓝奏远端消息、诊断明细会原样显示。
- macOS / Linux 的回收站撤销、机器码、单实例锁、自更新只做过交叉编译与静态检查，未真机运行。
- 本次未做启动烟测（避免占用桌面），窗口创建、WebView2 加载与界面交互需在实际运行中确认。
- 托盘点击、拖放落点、F1/Esc、全盘卷枚举、Everything 真实查询、危险源拒绝的 UI 触发等桌面交互项，均在 `docs/ui-shell.md` 未验证清单中逐条标注，未写成通过。
